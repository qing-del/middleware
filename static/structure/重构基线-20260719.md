## 五、跨模块 SQL 基线与消除目标

以下读查询当前跨越了未来模块边界，迁移时应改为本模块查询后通过批量 API 补全：

- `ImageAuditMapper.xml`：JOIN `biz_image`、`sys_user`。
- `MetaAuditMapper.xml`：JOIN `biz_tag`、`sys_user`。
- `NoteAuditMapper.xml`：JOIN `biz_note`、`sys_user`。
- `ImageMapper.xml`：JOIN `biz_note_image_mapping` 统计图片引用。
- `NoteImageMappingMapper.xml`：JOIN `biz_image` 获取图片信息。
- `UserMapper.xml`：读取 `biz_note` 汇总用户数据。

同一限界上下文内部的 JOIN 可以保留，例如 Note 模块内部 Note、Topic、Tag 和关系表之间的 JOIN。跨模块写入必须通过 API，不能保留跨模块 Mapper 或 SQL 写操作。
